# https://powfinder.netlify.app/

This project was made during our course: Js with Frameworks.  We worked with Vue and Vite. 
Here's a list of stuff that makes this site work:

 - v-for | it renders the list of forecasts.
 - v-model | renders amount of days depending on number chosen in dropdown.
 - vue-router | displays the forecast list after the fetch has been called.
 - switch | depending on which location chosen switch choses correct case.
 - filter | chooses objects from the array of locations.
